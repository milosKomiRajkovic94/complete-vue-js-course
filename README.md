# 📘 Complete Vue.js Course

**Implementing the full project examples from O’Reilly course: _“Complete Vue.js 3 (Incl. Options and Composition API's, Vue Router, Vuex)”_.** by Lachlan Miller

(Course link: https://learning.oreilly.com/course/complete-vuejs-3/9781803245287/) 

A structured learning repository where each branch focuses on one primary **Vue.js feature**, helping you explore code examples and progressive implementations from beginner to advanced.

## 🚀 Repository Overview

This repository contains:

- A standalone branch for each major Vue.js concept
- Simple example projects to explore how features work in isolation
- Learn-by-doing code that matches sections commonly found in Vue.js courses and documentation: https://vuejs.org/
- Learn-by-doing code that matches sections commonly found in Vuex courses and documentation: https://vuex.vuejs.org/

---

## 📁 Branches & Focus Areas

Each branch in this repository illustrates a specific Vue feature. Use these as self-contained examples or combine them into a full application later.

| Branch | Feature | What You’ll Learn |
|--------|---------|------------------|
| `main` | Base Setup | All the content currently available and only rendered the latest one|
| `01-course-introduction` | Options and Composition API basics | Hello world application and number calculations app passing the props |
| `02-form-validation` | Reactivity System | `ref`, `computed`, and reactive state basics |
| `03-pokemon-project` | Emit and styling | Passing of clickable logic with emit events and special styling for Pokemon card elements |
| `04-number-composible` | Composibles | Composible custom hooks, `reactive`, `watch` usage |
| `05-microblog-project` | Custom store's with states | Usage of custom stores without vuex, render of test posts in iteration |
| `06-router-project` | vue-router | Handling routes, redirection by using router-vuew dependency |
| `07-vuex-project` | vuex | Handling of global Vuex state, and it's life cycle |

> _Note: Modify branch names above if your repo uses different naming conventions._

## 🧱 Getting Started

To explore example code on any branch:

1. **Clone the repo:**
   ```bash
   git clone https://github.com/milosKomiRajkovic94/complete-vue-js-course.git

2. **Checkout appropriate branch** if you want to see a certain content mentioned in the table;
3. **Install dependencies** install the dependencies with `npm` by doing `npm install`;
4. **Run dev environment** by doing `npm run dev`;
